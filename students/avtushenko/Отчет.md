### 1. Bounded Contexts и Сервисы

| Bounded Context | Сервис | Ответственность |
|----------------|--------|-----------------|
| Управление курсами | Course Service | CRUD курсов, управление уроками |
| Записи и прогресс | Enrollment Service | Запись на курсы, отслеживание прогресса |
| Уведомления | Notification Service | Email/WebSocket уведомления |

### 2. Course Service

**API Endpoints:**

| Method | Endpoint | Описание |
|--------|----------|----------|
| POST | `/api/v1/courses` | Создать курс |
| GET | `/api/v1/courses/{id}` | Получить курс |
| GET | `/api/v1/courses` | Список курсов |
| GET | `/health` | Health check |

**Публикуемые события:**
- `CourseCreatedEvent` — при создании курса

**Пример запроса:**
```bash
curl -X POST http://localhost:8001/api/v1/courses \
  -H "Content-Type: application/json" \

```

### 6. API Gateway (Nginx)

**Маршрутизация:**
```
Path |	Target |	Port
/api/v1/courses* |	course-service |	8001
/api/v1/enrollments* |	enrollment-service |	8002
/ws/* |	enrollment-service (WebSocket) |	8002
```

**Конфигурация Nginx:**
```nginx
location /api/v1/courses {
    proxy_pass http://course-service:8001;
    proxy_connect_timeout 5s;
    proxy_read_timeout 30s;
}

location /api/v1/enrollments {
    proxy_pass http://enrollment-service:8002;
}

location /ws/ {
    proxy_pass http://enrollment-service;
    proxy_http_version 1.1;
    proxy_set_header Upgrade $http_upgrade;
    proxy_set_header Connection "upgrade";
}
```

## Вывод

Реализована микросервисная архитектура для системы мини-курсов «Учусь быстро»:
- 3 микросервиса: Course Service, Enrollment Service, Notification Service
- Изолированные БД: PostgreSQL для Course и Enrollment сервисов
- Асинхронная коммуникация: RabbitMQ event bus (4 типа событий)
- API Gateway: Nginx с маршрутизацией на порт 80
- Отказоустойчивость: Circuit Breaker с retry логикой через tenacity
- Оркестрация: Docker Compose (7 контейнеров)
Достигнута слабая связанность (loose coupling) между сервисами. Каждый сервис может быть развёрнут независимо. События гарантируют eventual consistency. API Gateway предоставляет единую точку входа.
