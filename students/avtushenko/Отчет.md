### 2. REST Controller (FastAPI)

**Эндпоинты API:**

| Метод | Path | Описание |
|-------|------|----------|
| POST | `/api/v1/courses` | Создать курс |
| POST | `/api/v1/enrollments` | Записать студента |
| POST | `/api/v1/enrollments/{id}/lessons/{lesson}/complete` | Завершить урок |
| POST | `/api/v1/enrollments/{id}/lessons/{lesson}/test` | Пройти тест |
| GET | `/api/v1/courses/{id}` | Получить курс |
| GET | `/api/v1/courses` | Список курсов |
| GET | `/api/v1/students/{student}/progress/{course}` | Прогресс студента |
| GET | `/api/v1/health` | Health check |

**Пример запроса (curl):**
```bash
# Создание курса
curl -X POST http://localhost:8000/api/v1/courses \
  -H "Content-Type: application/json" \
  -d '{"title":"Python Basics","description":"Learn Python"}'

# Ответ: {"id":"COURSE-ABC123","message":"Course created successfully"}

# Запись студента
curl -X POST http://localhost:8000/api/v1/enrollments \
  -H "Content-Type: application/json" \
  -d '{"student_id":"STU001","course_id":"COURSE-ABC123"}'

# Получение прогресса
curl http://localhost:8000/api/v1/students/STU001/progress/COURSE-ABC123

## Контрольные вопросы

1. **Почему Repository находится в Infrastructure, а не в Domain?**
   - Repository — это техническая деталь (работа с БД). Domain слой не должен зависеть от способа хранения данных. Инверсия зависимостей через интерфейс в Application/Port.

2. **В чём преимущество ORM над обычным SQL?**
   - ORM (SQLAlchemy) предоставляет: объектное отображение (снижает boilerplate), защиту от SQL-инъекций, абстракцию от диалекта SQL, автоматическую миграцию (Alembic), управление связями между таблицами.
 ```
