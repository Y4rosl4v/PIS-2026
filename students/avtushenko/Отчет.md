### 2. Read Model (Query Model)

**Read Models (денормализованные):**

| Read Model | Назначение | Денормализованные поля |
|------------|------------|----------------------|
| `CourseReadModel` | Детальная информация о курсе | total_students, average_progress, completed_students |
| `CourseSummaryReadModel` | Список курсов | total_students, average_progress (предвычислено) |
| `EnrollmentReadModel` | Прогресс студента | course_title, progress_percent |
| `StudentProgressReadModel` | Агрегированный прогресс | total_courses, completed_courses |

**Схема Read Model:**
┌─────────────────────────────────────────────────────────┐
│ Read Model │
├─────────────────────────────────────────────────────────┤
│ │
│ ┌─────────────────────────────────────────────────┐ │
│ │ course_statistics_mv (Materialized) │ │
│ ├─────────────────────────────────────────────────┤ │
│ │ course_id, total_enrollments, completed_... │ │
│ │ avg_progress, avg_rating, last_updated │ │
│ └─────────────────────────────────────────────────┘ │
│ │
│ ┌─────────────────────────────────────────────────┐ │
│ │ student_progress_cache (Cache Table) │ │
│ ├─────────────────────────────────────────────────┤ │
│ │ student_id, course_id, progress_percent, │ │
│ │ completed_lessons, completed_at, last_updated │ │
│ └─────────────────────────────────────────────────┘ │
│ │
│ Денормализовано: агрегированные данные предвычислены │
└─────────────────────────────────────────────────────────┘


**Пример Read Model Query (оптимизированный):**
```sql
-- Получение курса с агрегированными данными (один запрос вместо 3+)
SELECT 
    c.id, c.title, c.description, c.rating,
    COALESCE(l.lesson_count, 0) as total_lessons,
    COALESCE(e.total_students, 0) as total_students,
    COALESCE(e.avg_progress, 0) as average_progress
FROM courses c
LEFT JOIN (SELECT course_id, COUNT(*) as lesson_count FROM lessons GROUP BY course_id) l ...
LEFT JOIN (SELECT course_id, COUNT(*) as total_students, ... FROM enrollments GROUP BY course_id) e ...
WHERE c.id = :course_id
---
```

### 3. Event-Driven Sync

**Архитектура синхронизации:**
```
┌──────────────┐     ┌──────────────┐     ┌──────────────┐
│ Write Model  │────▶│   Domain     │────▶│   Event      │
│ (Enrollment) │     │   Events     │     │   Bus        │
└──────────────┘     └──────────────┘     └──────────────┘
                                                   │
                                                   ▼
┌──────────────┐     ┌──────────────┐     ┌──────────────┐
│ Read Model   │◀────│  Projection  │◀────│   Event      │
│ (PostgreSQL) │     │  Handlers    │     │  Handlers    │
└──────────────┘     └──────────────┘     └──────────────┘
```


**Обработчики событий:**
```
Событие	| Проекция	| Действие
EnrollmentStartedEvent	| ProgressProjection | Создать запись в student_progress_cache
LessonCompletedEvent	| ProgressProjection | Обновить progress_percent
CourseCompletedEvent	| ProgressProjection | Отметить completed_at
EnrollmentStartedEvent	| CourseProjection	| Обновить course_statistics_mv
LessonCompletedEvent	| CourseProjection | Обновить course_statistics_mv
CourseCompletedEvent	| CourseProjection | Обновить course_statistics_mv
```

**Код:**
```python
class EventHandlers:
    def _handle_lesson_completed(self, event: LessonCompletedEvent) -> None:
        # Обновляем кэш прогресса студента
        self._progress_projection.on_lesson_completed(event)
        # Обновляем статистику курса
        self._course_projection.refresh_course_statistics_by_enrollment(event.enrollment_id)
```

### 4. Оптимизация запросов

**Индексы (PostgreSQL):**
```
Таблица	| Индекс	| Назначение
enrollments	| idx_enrollments_student_course | Быстрый поиск по студенту+курсу
enrollments	| idx_enrollments_course_progress| Сортировка по прогрессу
courses	| idx_courses_rating | Топ курсов по рейтингу
courses	| idx_courses_created | Сортировка по дате
```

**Материализованное представление:**
```sql
CREATE MATERIALIZED VIEW course_statistics_mv AS
SELECT 
    c.id AS course_id,
    COUNT(DISTINCT e.id) AS total_enrollments,
    COALESCE(AVG(CASE WHEN e.total_lessons > 0 
        THEN (json_array_length(e.completed_lessons)::float / e.total_lessons) * 100
        ELSE 0 END), 0) AS avg_progress
FROM courses c
LEFT JOIN enrollments e ON c.id = e.course_id
GROUP BY c.id;
```

**Таблица-кэш для быстрых запросов:**
```sql
CREATE TABLE student_progress_cache (
    student_id VARCHAR(50) NOT NULL,
    course_id VARCHAR(50) NOT NULL,
    progress_percent INTEGER DEFAULT 0,
    completed_lessons JSONB DEFAULT '[]',
    last_updated TIMESTAMP DEFAULT NOW(),
    PRIMARY KEY (student_id, course_id)
);
```

    handlers = EventHandlers(db_session)
    event = LessonCompletedEvent("E1", "L1", 50)
    
    handlers.handle(event)
