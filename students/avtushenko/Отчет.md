### 2. Entities (Сущности)

**Созданные Entity:**

1. **Course** - курс обучения
   - ID поле: `_id`
   - Бизнес-правила: нельзя добавить один урок дважды
   - Файл: `domain/entities/course.py`

2. **Lesson** - урок с видео и тестом
   - ID поле: `_id`
   - Бизнес-правила: тест можно прикрепить только один раз
   - Файл: `domain/entities/lesson.py`

**Пример кода** (Course):
```python
class Course:
    def __init__(self, course_id: str, title: str, description: str):
        self._id = course_id
        self._title = title
        self._description = description
        self._lessons: List[str] = []

    def add_lesson(self, lesson_id: str) -> None:
        if lesson_id in self._lessons:
            raise ValueError(f"Lesson {lesson_id} already in course")
        self._lessons.append(lesson_id)
```

**Aggregate Root:** Enrollment (запись студента на курс)

- Корень: `Enrollment`
- Внутренние сущности: `нет (ссылается на Course и Lesson по ID)`

**Инварианты агрегата:**

| № | Инвариант | Как проверяется |

**Пример кода Aggregate Root:**
```python
def complete_lesson(self, lesson_id: str) -> None:
    if lesson_id in self._completed_lessons:
        raise ValueError(f"Lesson {lesson_id} already completed")
    self._completed_lessons.append(lesson_id)
    self._register_event(LessonCompletedEvent(...))
    if self.progress.value == 100:
```

## Контрольные вопросы

1. **В чём отличие Value Object от Entity?**
   - Value Object не имеет собственной идентичности и определяется своими атрибутами (иммутабелен). Entity имеет уникальный ID и может изменять состояние. Два Value Object с одинаковыми полями равны, две Entity равны только при совпадении ID.

2. **Почему Aggregate Root должен инкапсулировать доступ к внутренним сущностям?**
   - Чтобы обеспечить соблюдение бизнес-инвариантов. Внешний код не должен изменять внутренние объекты в обход корня, иначе можно нарушить целостность агрегата.

3. **Какая роль Domain Events? Приведите пример из вашей системы.**
   - Фиксация важных событий домена для дальнейшей обработки (уведомления, логирование, саги). Пример: CourseCompletedEvent — при завершении курса можно выдать сертификат.

4. **Как вы проверяете инварианты в вашем агрегате? Приведите пример.**
   - Через защиту публичных методов. Пример: в complete_lesson() проверяем, не завершён ли уже урок, и выбрасываем ValueError.

5. **Почему Value Objects делаются иммутабельными?**
   - Чтобы гарантировать, что их состояние не изменится после создания. Это позволяет безопасно разделять их между объектами и избегать побочных эффектов.
