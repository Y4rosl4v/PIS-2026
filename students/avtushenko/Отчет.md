```python
@pytest.mark.integration
class TestCourseRepository:
    def test_save_and_find_course(self, db_session):
        repo = CourseRepository(db_session)
        course = Course("C1", "Python Basics", "Learn Python")
        
        repo.save(course)
        found = repo.find_by_id("C1")
        
        assert found is not None
        assert found.title == "Python Basics"
```

### 4.  E2E-тесты

**Сценарий:** Полный путь студента
```
1. POST /api/v1/courses     → Создание курса
2. GET /api/v1/courses/{id} → Проверка создания
3. POST /api/v1/enrollments → Запись студента
4. GET /api/v1/students/... → Проверка прогресса
5. GET /api/v1/health       → Проверка состояния
```

**Набор тестов:**
| Сценарий | Кол-во тестов | Проверяемые эндпоинты |
|-----------|---------------|-------------------|
| Course Flow | 3 | create, get, list, 404 handling |
| Student Journey | 3 | enrollment, progress, health |
| Error Handling | 2 | not found, validation |

**Пример теста с testcontainers:**
```python
def test_full_course_creation_flow(self, test_client):
    # Create course
    response = test_client.post("/api/v1/courses", json={
        "title": "E2E Test Course",
        "description": "Testing full flow"
    })
    assert response.status_code == 201
    course_id = response.json()["id"]
    
    # Get course
    response = test_client.get(f"/api/v1/courses/{course_id}")
    assert response.status_code == 200
    assert response.json()["title"] == "E2E Test Course"
```
